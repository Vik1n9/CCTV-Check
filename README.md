# CCTV 點檢系統

行動裝置優先的 CCTV 監視迴路點檢工具。單一 HTML 檔、純前端、無需安裝或後端,以手機開啟即可逐台主機點檢每個迴路(CH)的狀態,並匯出/匯入 CSV 報表。

## 線上使用

- **正式版(建議)**:<https://vik1n9.github.io/CCTV-Check/>
- 舊版 v2:<https://vik1n9.github.io/CCTV-Check/claudev2.html>
- 原始碼:<https://github.com/Vik1n9/CCTV-Check>

> 手機瀏覽器開啟後,可用「加入主畫面」當成 App 使用(已設定 iOS 全螢幕與主題色)。

## 功能

| 功能 | 說明 |
|---|---|
| 逐主機點檢 | 以 ◀ ▶ 按鈕、左右滑動(手機)或鍵盤方向鍵切換主機 |
| 三種狀態 | 🟢 正常(預設)/ 🔴 故障 / ⚠️ 異常;點擊迴路方塊依序循環切換 |
| 篩選 | 全部 / 故障 / 異常 / 正常 |
| 快速全設 | 將當前主機所有迴路一次設為正常、故障或異常 |
| 重置 | 重置當前主機,或重置全部點檢狀態(保留主機清單) |
| 總覽頁 | 全場統計與各主機狀態條,點擊卡片可跳回該主機 |
| 匯出報表 | 下載 CSV(含 UTF-8 BOM,可直接以 Excel 開啟) |
| 導入報表 | 讀入先前匯出的 CSV,還原主機配置與點檢狀態 |
| 自動儲存 | 每次操作即時存入瀏覽器 `localStorage`,重新整理不會遺失 |

## 預設主機

內建 21 台主機:A、B、C、D、E、F、G、H、I、J、K1、K2、L、M、N、O、P、Q1、Q2、R、S。其中 G、H、I 為「已拆除」(0 迴路,不可點檢)。各主機迴路數見 `index.html` 內的 `DEFAULT_HOSTS`。

## 報表格式(CSV)

欄位:`主機, CH總數, 故障編號, 故障數, 正常總數, 備註`

- 故障編號以逗號分隔,例如 `3,7,12`。
- 異常迴路記錄在備註,格式為 `異常通道: 5,9;待填寫原因`。
- `CH總數` 為 0 的主機視為已拆除;`CH總數` > 0 一律視為存在(忽略備註中的拆除字樣)。
- 最後一列「全場總計」匯入時會被略過。

**導入會完全取代目前的主機清單與點檢狀態**,導入前如需保留請先匯出。

## 資料與隱私

- 所有資料只存在使用者瀏覽器的 `localStorage`(key:`cctv_dynamic_v5`),不會上傳到任何伺服器。
- 換瀏覽器或裝置、清除網站資料後,記錄不會跟著走;請以匯出的 CSV 備份與轉移。

## 本機執行

不需建置,直接用瀏覽器開啟 `index.html` 即可;或在目錄內啟動任一靜態伺服器:

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000/
```

## 檔案

- `claudev2.html`:早期版本(無 CSV 導入功能,使用 Google Fonts,儲存 key 為 `cctv_v2_state`)
